# CampusEats

SE3090 Lab 08 task tracker and Lab 11 cloud deployment.

- `.github/workflows/campuseats-cloud-ci.yml`: frontend/API build checks.

See [Lab 11 deployment guide](LAB11_DEPLOYMENT.md) for configuration and evidence.
